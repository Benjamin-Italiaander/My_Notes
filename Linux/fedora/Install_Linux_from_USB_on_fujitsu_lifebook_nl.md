Ik wilde Fedora 36 vanaf USB installeren op mijn Fujitsu Lifebook U7410, maar hij wilde niet opstarten vanaf de USB-stick:

```text
set_second_stage() failed: invalid Parameter
Something has gone seriously wrong: shim_init() failed Invalid Parameter
```

Je voorkomt dit probleem door de opstartbare USB-stick te maken met [Ventoy](https://www.ventoy.net/en/index.html).
