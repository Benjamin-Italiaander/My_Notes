# Markdown-bestanden lezen op de Linux-commandoregel

- [Glow](https://github.com/charmbracelet/glow): een handige tool die ik tegenkwam. Goed onderhouden en makkelijk in gebruik.
- [Frogmouth](https://github.com/Textualize/frogmouth): een eenvoudige Markdown-viewer voor de CLI, gebouwd met [Textual](https://github.com/Textualize/textual).
- [mdless](https://github.com/ttscoff/mdless): lijkt niet regelmatig onderhouden te worden, maar geeft Markdown-bestanden goed weer in de CLI.
- [Markdown lint tool](https://github.com/markdownlint/markdownlint): voor de Markdown-puristen, een tool om je Markdown-bestanden te controleren. Niet goed onderhouden.
